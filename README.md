## WEB Catálogo de Cursos - Holguín

WEB edu-hlg-web, para la gestión de un catálogo de cursos públicos y privados en la provincia de Holguín, Cuba. Desarrollada inicialmente para atender las necesidades de la empresa Desoft, pero con alcance provincial para beneficio de toda la comunidad.

### Descripción del Proyecto

Esta web constituye el frontend de un sistema de catálogo de cursos para la provincia de Holguín, 

El proyecto nace de la necesidad de centralizar y digitalizar la oferta educativa en la provincia, facilitando el acceso a la información sobre cursos disponibles tanto en el sector estatal como privado.

### Tecnologías Utilizadas

- ANGULAR-CLI v-16
- Node cli v-16
